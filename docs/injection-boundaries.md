# AI出力・過去AI生成物の境界

## 対象と判断

返信案に含まれる認証情報の共有要求を、生成・保存済み結果の取得・画面表示・コピーの各入口で検査する。検出した場合は分析全体を停止し、部分結果を利用者へ返さない。保存済み結果では原本を保持し、表示停止を示す応答へ置き換える。停止画面から追加の分析や自動再試行はしない。

新しい分析には、AIが生成した過去相談の要約・PersonProfile・UserPatternSummaryを自動投入しない。DB文脈構築では取得せず、送信直前にも除外する。これらの原本と既存設定は保持する。許可済みの本人Feedbackだけは、所有者・人物・利用設定・個別許可を条件に、指示権限のない参考データとして渡す。画面の設定案内もこの範囲に合わせる。

この選択により、AI要約・Profileを使った従来の個人化は停止する。削除や新しいDB状態、追加の有料判定器は導入しないため、後から再設計できる。固定プロンプト・認証・課金設定・既存のrun/CAS・利用枠精算は変更しない。

## 表現検査の範囲と限界

`modelContentPolicy.ts`は日本語・英語の既知表現を対象に、認証情報と送信・共有・サイト入力等の関係を検査する。既存の診断断定・暴力や脅迫等の表現検査も共有し、生成だけでなく保存済み結果・旧キャッシュ・コピーに適用する。URLや「パスワード」という語だけでは拒否しない。限定した報告引用・否定文は許可し、引用後の追従要求は指示として検査する。分析欄へ指示を移した場合も検査対象とする。

これは有限のルールであり、意味を網羅する分類器ではない。言い換え、複雑な引用・否定、間接的な指示、未知の言語には検出漏れと誤検知が残る。「危険な文章が絶対に表示されない」ことを保証しない。独立レビューで再現された引用追従・送付の検出漏れと、報告・不要を表す正常文の誤検知には回帰検証を加えた。

AI生成物の自動持越し経路は除外するが、本人が相談やFeedbackに転記する経路は残る。過去にコピー・表示済みの文章は回収しない。新しい画面コードを受け取っていない既存タブの動作を遡って変更する機能もない。実モデルの指示追従、解釈の品質、総合的な攻撃成功率は今回測定しない。

## 未実施の検証

実課金API、実Auth・メール、共有DB、ブラウザ実画面、本番環境では実行しない。PostgreSQLの実競合や制約の追加検証も今回行わない。DB schemaと認証・利用枠の仕組みは変更しない。検証用のモックや限定した表現ルールを、包括的な安全性・請求額・本番運用の保証として扱わない。
