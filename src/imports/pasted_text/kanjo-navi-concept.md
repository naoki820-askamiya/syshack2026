作品名

感情ナビ（仮）

コンセプト

人間関係で起きる「相手の機嫌が分からない」「どう対応すればいいか分からない」という悩みに対して、
状況を分析し、“次に取るべき具体的な行動”を提示するサポートアプリ。

単なる相談ではなく、
実際に使える行動（メッセージ・対応）を即座に提示することを目的とする。

ターゲットユーザー

上司や同僚との関係に悩む社会人

恋人や友人とのコミュニケーションに不安を感じる人

人間関係で「どう動けばいいか迷う人」

提供価値

相手の感情を客観的に整理できる

すぐに使える行動が分かる

間違った対応（悪化する行動）を避けられる

■ 主な機能
① 状況入力（構造化フォーム）

ユーザーが状況を整理して入力できるUI

入力項目

相手との関係（上司 / 恋人 / 友人 など）

起きた出来事（選択式＋自由記述）

相手の反応（怒っている / 無視 / 冷たい など）

自分の行動

現在の状況（直後 / 数時間後 / 翌日など）

② 感情分析（結果表示）

入力内容から相手の状態を可視化

表示内容

機嫌レベル（良い / 普通 / 悪い）

感情タイプ（怒り / 悲しみ / 不満 など）

危険度（低 / 中 / 高）

③ 行動提案（コア機能）
1. 推奨アクション

「今すぐ謝る」

「少し時間を置く」

「軽くフォローする」

2. 具体メッセージ生成（最重要）

ユーザーがそのまま使える文章を提示

例：
「昨日は言い方きつくてごめん。ちょっと余裕なくて当たっちゃった。」

3. NG行動提示

やってはいけない行動を明示

例：

今は長文を送らない

追いメッセージは逆効果

④ 履歴・人物管理

相手ごとに履歴を保存（上司A、恋人Bなど）

過去のトラブルや傾向を蓄積

⑤ 感情の可視化UI

機嫌メーター（絵文字やゲージ）

状況の分かりやすいビジュアル表示

■ 画面構成（UI構造）
1. ホーム画面

「相談を開始」ボタン

登録済みの人物一覧

2. 入力画面

フォーム形式で状況入力

選択式＋テキスト入力

3. 分析結果画面

感情メーター表示

状況の要約

4. 行動提案画面

推奨アクション

メッセージ例（コピー可能）

NG行動リスト

5. 履歴画面

過去の相談一覧

人物ごとの記録

■ UXの特徴（差別化ポイント）

自由入力ではなく、構造化された入力

抽象的なアドバイスではなく、具体的な行動提示

「何をすればいいか」を即決できる設計

同じ相手に対する継続的な関係性の管理

■ トーン・デザイン方向性

親しみやすい（柔らかい色合い）

感情が直感的に分かるUI（絵文字・色）

シンプルで迷わない操作性

■ 一言キャッチコピー

👉「次に送る一言、もう迷わない。」
